# @deepseek-ai/dsh-client-ui-team-tasks

[English](README.md) | 中文

Web 团队任务看板功能：对话界面上方的浮动按钮 + 它打开的共享看板对话框。团队成员提交任务与 bug、查看状态泳道，并通过宿主的 `teamTasks` RPC 域驱动状态流转。纯展示——所有 wire 调用都通过注入的回调到达，看板状态保持在组件内部。

## 模型体验

无，因为看板只渲染与变更持久化的任务数据，从不触碰会话请求。

#### KV Cache 影响

看板操作从不进入会话请求，因此不影响任何 KV cache。

## 已知限制与后续工作

- 看板先提供标题、优先级、备注与状态流转；原工具链的板块、模型选择、截止日期与任务附件被推迟。
- AI 自动处理按钮（派发 subagent 分析并尝试修复）是独立的宿主 consumer，被推迟。
- 看板文案为硬编码中文；locale 命名空间座位被推迟。
