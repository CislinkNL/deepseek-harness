# @deepseek-ai/dsh-team-tasks

[English](README.md) | 中文

共享团队任务看板 seam（`ctx.teamTasks`）。这是唯一刻意不复用单会话日志的存储：团队看板是共享、多用户、跨会话的，因此需要自己的持久化。Provider 实现 CRUD 并强制执行状态机（`todo → doing | human | done`，`done` 只能回 `doing`）；消费者是 Web 看板界面与 AI 自动处理循环。

## 模型体验

间接生效，通过把任务内容渲染进被派发 agent 上下文的 AI 处理消费者。

#### KV Cache 影响

看板变更从不触碰会话请求，因此任务变化不会使任何会话 KV cache 失效；只有消费者派发的轮次会物化任务文本。

## 已知限制与后续工作

- 存储是单一共享文档；多写者合并语义与事件日志被推迟。
- 板块词表与模型路由是部署定义的字符串；校验是消费者的职责。
- AI 自动处理（分析与修复派发）是独立消费者，不属于本 seam。
